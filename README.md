# Allet legal site

Static source for a separate public GitHub Pages repository named `Allet-Legal`.

Before publishing, complete a final legal review of the privacy disclosures and terms.

Do **not** publish this directory from `Allet-Docs`: that repository contains internal documentation. Copy these files into a separate, public `Allet-Legal` GitHub repository, then enable GitHub Pages from its `main` branch and the repository root.

Expected GitHub Pages routes:

- `/privacy/`
- `/terms/`
- `/support/`
